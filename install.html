🔧 Installation — étape par étape

1

Important : le téléchargement doit se faire avec Google Chrome.
Ouvrez cette page dans Chrome (pas un autre navigateur), puis touchez le bouton « Télécharger Glycotrace ».

2

Touchez le bouton « Télécharger Glycotrace » ci-dessus.

3

Après le téléchargement, ouvrez le fichier glycotrace.apk (depuis la barre de notifications ou le dossier « Téléchargements »).

4

Android affiche un avertissement « Installation d'applications inconnues ».
Touchez Paramètres puis autorisez « Installer des applications inconnues » pour le navigateur (Chrome).
Revenez en arrière et redémarrez l'installation.

5

Cliquez sur « Installer », puis à la fin sur « Ouvrir ». Done ! 🎉

⚠️ L'avertissement « source inconnue » est normal : Glycotrace n'est pas distribué via le Play Store. L'installation est sûre — rien ne quitte votre appareil.

❓ Questions fréquentes

Pourquoi faut-il Chrome ?
L'application utilise le moteur de Google Chrome pour s'afficher en plein écran. Sans Chrome installé (et défini comme navigateur par défaut), l'installation fonctionnera mais l'application s'ouvrira dans une fenêtre de navigateur classique.

Que se passe-t-il après les 14 jours ?
L'app affiche « Version de test expirée » et bloque l'accès. Vos données ne sont pas perdues — contactez l'éditeur pour obtenir la version complète.

Mon téléphone est-il compatible ?
Tout Android récent (Android 8+) avec Chrome suffit. Internet est nécessaire seulement au premier lancement.

Vos données sont-elles envoyées en ligne ?
Non. Toutes vos données (repas, historique, identité) sont enregistrées uniquement sur votre appareil.

Une nouvelle version est-elle sortie ?
Revenez sur cette page : la version affichée en haut vous dira si une mise à jour est disponible.

Glycotrace est un outil éducatif d'estimation — il ne remplace ni un avis médical ni un lecteur de glycémie.
